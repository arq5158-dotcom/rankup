# Rank Up

Live prize leaderboard. Pay, climb, win.

Cinematic black-and-gold competition site with monthly and weekly prize pools, Stripe checkout, accounts, and a live ranking board.

## Stack

- TanStack Start + React 19
- Tailwind CSS
- Better Auth
- Stripe
- Postgres / PGLite

## Scripts

```bash
npm install
npm run dev
npm run build
npm run typecheck
```

Rankings update only after payment confirms.
